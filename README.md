# 🍳 Kitchen Rush

**Kitchen Rush** é um jogo de gerenciamento e cooperação em um ambiente de cozinha, desenvolvido no GameMaker. O jogador deve organizar os ingredientes, preparar alimentos e atender aos pedidos dentro de um determinado período de tempo, buscando alcançar a maior pontuação possível.

O projeto combina a dinâmica e o gerenciamento de tarefas de jogos como **Overcooked** com elementos de interação, organização e personalização de ambientes inspirados em **Habbo**.

## 🎮 Sobre o Projeto

O objetivo do jogo é administrar uma cozinha de maneira eficiente, realizando as etapas necessárias para preparar e entregar os pedidos dos clientes.

Durante as partidas, o jogador deverá interagir com diferentes objetos e estações de trabalho, organizar os ingredientes e controlar o tempo de preparo dos alimentos.

O projeto está em desenvolvimento e busca implementar suas mecânicas gradualmente, desde as interações básicas até sistemas mais completos de pedidos e gerenciamento da cozinha.

## 🎯 Objetivos

- Desenvolver um jogo de cozinha utilizando o GameMaker.
- Implementar mecânicas de movimentação e interação com objetos.
- Criar sistemas de coleta, corte e cozimento de ingredientes.
- Desenvolver um sistema de pedidos e entrega de alimentos.
- Implementar pontuação e gerenciamento de tempo.
- Explorar conceitos de lógica de programação e desenvolvimento de jogos.

## 🕹️ Principais Mecânicas

- **Movimentação e interação:** movimentar o personagem e interagir com objetos da cozinha.
- **Gerenciamento de ingredientes:** coletar, transportar e organizar ingredientes.
- **Preparação de alimentos:** realizar etapas como cortar e cozinhar os ingredientes.
- **Atendimento de pedidos:** preparar os alimentos solicitados e entregá-los dentro do tempo disponível.
- **Pontuação:** avaliar o desempenho do jogador com base no atendimento dos pedidos.

## 📂 Estrutura do Projeto

O projeto é organizado em recursos do GameMaker, separados conforme suas responsabilidades.

- `objects/` — objetos do jogo, personagens, ingredientes e estações de trabalho.
- `sprites/` — imagens e elementos visuais.
- `rooms/` — ambientes e cenários.
- `scripts/` — scripts e funções reutilizáveis, quando aplicável.
- `KitchenRush.yyp` — arquivo principal do projeto GameMaker, caso esse seja seu nome real.

## 🚀 Como Executar

1. Instale o GameMaker em uma versão compatível com o projeto.
2. Clone este repositório ou baixe os arquivos do projeto.
3. Abra o GameMaker.
4. Abra o arquivo `.yyp` do projeto.
5. Execute o jogo pelo ambiente de desenvolvimento.
